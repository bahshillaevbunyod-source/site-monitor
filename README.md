# Монитор сайтов с Telegram-ботом

Раз в 5 минут заходит на сайты как посетитель, проверяет, что они открываются, и при сбое пишет в Telegram. Когда сайт ожил, пишет «снова работает». Сайты только читает.

Статус: этап 1 (подготовка). Подробное описание появится на этапе 7.

## Секреты
Лежат в `.env.local` (в git не попадает):
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
